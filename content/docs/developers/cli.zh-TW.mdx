使用 S.EE CLI，可直接在終端機中建立和管理短網址、文字片段和檔案。

- [sdotee/cli](https://github.com/sdotee/cli)

## 功能

- **短網址管理**：建立、更新和刪除帶自訂別名、網域和過期時間的短網址
- **文字片段**：從 stdin 或檔案中分享程式碼片段和筆記
- **檔案上傳**：直接上傳檔案，或透過 stdin 上傳
- **網域和標籤管理**：列出可用網域並管理標籤
- **密碼保護**：使用密碼保護您的內容
- **JSON 輸出**：適用於指令碼的機器可讀輸出

## 安裝

### macOS

```bash
brew tap sdotee/homebrew-tap
brew install see
```

### Debian / Ubuntu / RHEL（xTom 套件庫）

[xTom](https://xtom.com/) 在其 [APT 和 DNF 套件庫](https://github.com/xtomcom/repo)中提供了 CLI 的 `amd64` 和 `arm64` 安裝套件，之後可以透過 `apt upgrade` 或 `dnf upgrade` 更新。支援的系統：Debian 12 和 13，Ubuntu 22.04、24.04 和 26.04 LTS，以及 RHEL、Rocky Linux 和 AlmaLinux 9 和 10。

快速設定，自動為您的系統新增套件庫：

```bash
curl -sL ba.sh/repo | sudo bash
```

接著安裝 `see` 套件：

```bash
# Debian / Ubuntu
sudo apt install see

# RHEL / Rocky / AlmaLinux
sudo dnf install see
```

也可以手動新增套件庫：

```bash
# Debian / Ubuntu
sudo apt install -y ca-certificates curl gnupg
curl -fsSL https://repo.xtom.com/xtom.key | sudo bash -c 'gpg --dearmor > /usr/share/keyrings/xtom.gpg'
echo "deb [signed-by=/usr/share/keyrings/xtom.gpg] https://repo.xtom.com/deb stable main" | sudo tee /etc/apt/sources.list.d/xtom.list
sudo apt update
sudo apt install see

# RHEL / Rocky / AlmaLinux
sudo curl -o /etc/yum.repos.d/xtom.repo https://repo.xtom.com/rpm/xtom.repo
sudo dnf install see
```

在 Debian 上也可以執行 `sudo extrepo enable xtom` 新增套件庫。更多方式請參閱 [xTom 套件庫說明](https://github.com/xtomcom/repo#usage)。

### .deb / .rpm 安裝套件

如果不想新增套件庫，可以從 [GitHub Releases](https://github.com/sdotee/cli/releases) 下載單一安裝套件：

```bash
# Debian / Ubuntu
sudo dpkg -i see-cli_<version>_<arch>.deb

# RHEL / Fedora
sudo rpm -i see-cli_<version>_linux_<arch>.rpm
```

### Arch Linux

```bash
yay -S see-cli
# 或安裝預先編譯的二進位版本
yay -S see-cli-bin
```

### 從原始碼安裝

```bash
go install github.com/sdotee/cli@latest
```

預先編譯的二進位檔案和安裝套件可從 [GitHub Releases](https://github.com/sdotee/cli/releases) 下載。

## 設定

透過環境變數或參數設定 API 金鑰：

```bash
# 環境變數（推薦）
export SEE_API_KEY="your-api-key"

# 或透過參數使用
see --api-key "your-api-key" <command>
```

### 設定選項

| 選項 | 環境變數 | 說明 |
|--------|---------------------|-------------|
| `--api-key` | `SEE_API_KEY` | 您的 S.EE API 金鑰（必填） |
| `--base-url` | `SEE_BASE_URL` | 自訂 API 基底 URL |
| `--timeout` | `SEE_TIMEOUT` | 請求逾時時間 |
| `--json` | - | 啟用 JSON 輸出格式 |

## 命令

### 網域和標籤

```bash
# 列出短網址可用網域
see domains

# 列出檔案上傳可用網域
see file domains

# 列出您的標籤
see tags
```

### 短網址

```bash
# 建立短網址
see url create https://example.com

# 使用自訂選項建立
see url create https://example.com \
  --slug my-link \
  --domain s.ee \
  --title "My Link" \
  --password secret \
  --expires 2024-12-31

# 更新短網址
see url update --domain s.ee --slug my-link --title "New Title"

# 刪除短網址
see url delete --domain s.ee --slug my-link
```

### 文字片段

```bash
# 從 stdin 建立文字
echo "Hello World" | see text create --title "greeting"

# 從檔案建立文字
see text create --file ./snippet.txt --title "Code Snippet"

# 使用選項建立
cat script.sh | see text create \
  --title "Shell Script" \
  --domain ba.sh \
  --password secret \
  --expires 2024-12-31

# 更新文字
see text update --domain ba.sh --slug demo --title "Updated Title"

# 刪除文字
see text delete --domain ba.sh --slug demo
```

### 檔案上傳

```bash
# 上傳檔案
see file upload ./image.png

# 使用自訂網域上傳
see file upload ./document.pdf --domain fs.to

# 從 stdin 上傳
cat image.png | see file upload --stdin --filename image.png

# 刪除檔案
see file delete <delete-hash>
```

## JSON 輸出

使用 `--json` 參數取得機器可讀輸出，適合指令碼使用：

```bash
see url create https://example.com --json | jq '.short_url'
```

## 範例

### 建立短網址並複製到剪貼簿（macOS）

```bash
see url create https://example.com --json | jq -r '.short_url' | pbcopy
```

### 上傳截圖並取得 URL（Linux）

```bash
see file upload ~/screenshot.png --json | jq -r '.url'
```

### 批次建立短網址

```bash
while read url; do
  see url create "$url" --json
done < urls.txt
```
