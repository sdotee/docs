Use the S.EE CLI to create and manage short URLs, text snippets, and files from your terminal.

- [sdotee/cli](https://github.com/sdotee/cli)

## Features

- **Short URL Management**: Create, update, and delete shortened links with custom slugs, domains, and expiration
- **Text Snippets**: Share code snippets and notes from stdin or files
- **File Upload**: Upload files directly or via stdin
- **Domain & Tag Management**: List available domains and manage tags
- **Password Protection**: Secure your content with passwords
- **JSON Output**: Machine-readable output for scripting

## Installation

### macOS

```bash
brew tap sdotee/homebrew-tap
brew install see
```

### Debian / Ubuntu / RHEL (xTom repository)

[xTom](https://xtom.com/) packages the CLI in its [APT and DNF repository](https://github.com/xtomcom/repo) for `amd64` and `arm64`, so you get updates through `apt upgrade` or `dnf upgrade`. Supported systems: Debian 12 and 13, Ubuntu 22.04, 24.04 and 26.04 LTS, and RHEL, Rocky Linux and AlmaLinux 9 and 10.

Quick setup, which adds the repository for your system:

```bash
curl -sL ba.sh/repo | sudo bash
```

Then install the `see` package:

```bash
# Debian / Ubuntu
sudo apt install see

# RHEL / Rocky / AlmaLinux
sudo dnf install see
```

To add the repository by hand instead:

```bash
# Debian / Ubuntu
sudo apt install -y ca-certificates curl gnupg
curl -fsSL https://repo.xtom.com/xtom.key | sudo bash -c 'gpg --dearmor > /usr/share/keyrings/xtom.gpg'
echo "deb [signed-by=/usr/share/keyrings/xtom.gpg] https://repo.xtom.com/deb stable main" | sudo tee /etc/apt/sources.list.d/xtom.list
sudo apt update
sudo apt install see

# RHEL / Rocky / AlmaLinux
sudo curl -o /etc/yum.repos.d/xtom.repo https://repo.xtom.com/rpm/xtom.repo
sudo dnf install see
```

On Debian you can also run `sudo extrepo enable xtom` to add the repository. See the [xTom repository README](https://github.com/xtomcom/repo#usage) for more options.

### .deb / .rpm packages

To install a single package without adding a repository, download it from [GitHub Releases](https://github.com/sdotee/cli/releases):

```bash
# Debian / Ubuntu
sudo dpkg -i see-cli_<version>_<arch>.deb

# RHEL / Fedora
sudo rpm -i see-cli_<version>_linux_<arch>.rpm
```

### Arch Linux

```bash
yay -S see-cli
# or pre-built binary
yay -S see-cli-bin
```

### From Source

```bash
go install github.com/sdotee/cli@latest
```

Download pre-built binaries and packages from [GitHub Releases](https://github.com/sdotee/cli/releases).

## Configuration

Set your API key via environment variable or flag:

```bash
# Environment variable (recommended)
export SEE_API_KEY="your-api-key"

# Or use the flag
see --api-key "your-api-key" <command>
```

### Configuration Options

| Option | Environment Variable | Description |
|--------|---------------------|-------------|
| `--api-key` | `SEE_API_KEY` | Your S.EE API key (required) |
| `--base-url` | `SEE_BASE_URL` | Custom API base URL |
| `--timeout` | `SEE_TIMEOUT` | Request timeout |
| `--json` | - | Enable JSON output format |

## Commands

### Domains & Tags

```bash
# List available domains for short URLs
see domains

# List available domains for file uploads
see file domains

# List your tags
see tags
```

### Short URLs

```bash
# Create a short URL
see url create https://example.com

# Create with custom options
see url create https://example.com \
  --slug my-link \
  --domain s.ee \
  --title "My Link" \
  --password secret \
  --expires 2024-12-31

# Update a short URL
see url update --domain s.ee --slug my-link --title "New Title"

# Delete a short URL
see url delete --domain s.ee --slug my-link
```

### Text Snippets

```bash
# Create text from stdin
echo "Hello World" | see text create --title "greeting"

# Create text from file
see text create --file ./snippet.txt --title "Code Snippet"

# Create with options
cat script.sh | see text create \
  --title "Shell Script" \
  --domain ba.sh \
  --password secret \
  --expires 2024-12-31

# Update text
see text update --domain ba.sh --slug demo --title "Updated Title"

# Delete text
see text delete --domain ba.sh --slug demo
```

### File Upload

```bash
# Upload a file
see file upload ./image.png

# Upload with custom domain
see file upload ./document.pdf --domain fs.to

# Upload from stdin
cat image.png | see file upload --stdin --filename image.png

# Delete a file
see file delete <delete-hash>
```

## JSON Output

Use the `--json` flag for machine-readable output, useful for scripting:

```bash
see url create https://example.com --json | jq '.short_url'
```

## Examples

### Create a short URL and copy to clipboard (macOS)

```bash
see url create https://example.com --json | jq -r '.short_url' | pbcopy
```

### Upload screenshot and get URL (Linux)

```bash
see file upload ~/screenshot.png --json | jq -r '.url'
```

### Batch create short URLs

```bash
while read url; do
  see url create "$url" --json
done < urls.txt
```
