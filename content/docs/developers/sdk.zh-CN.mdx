使用官方 SDK 在应用中调用 [S.EE API](/docs/zh-CN/developers/api/)。各仓库的 README 中有完整的使用示例。不同 SDK 对较新接口的支持程度不同，请查看所选 SDK 的 README。

## 官方 SDK

| 语言 | 仓库 | 软件包 | 环境要求 |
|------|------|--------|----------|
| TypeScript / JavaScript | [sdotee/sdk.ts](https://github.com/sdotee/sdk.ts) | [`see-sdk`](https://www.npmjs.com/package/see-sdk) (npm) | |
| Go | [sdotee/sdk.go](https://github.com/sdotee/sdk.go) | `github.com/sdotee/sdk.go` | |
| Python | [sdotee/sdk.py](https://github.com/sdotee/sdk.py) | [`see-sdk`](https://pypi.org/project/see-sdk/) (PyPI) | Python 3.11 及以上 |
| Rust | [sdotee/sdk.rs](https://github.com/sdotee/sdk.rs) | [`see-sdk`](https://crates.io/crates/see-sdk) (crates.io) | |
| Swift | [sdotee/sdk.swift](https://github.com/sdotee/sdk.swift) | Swift Package Manager | Swift 6 及以上 |
| Java | [sdotee/sdk.java](https://github.com/sdotee/sdk.java) | `dev.s.ee:see-java-sdk` | Java 17 及以上 |
| PHP | [sdotee/sdk.php](https://github.com/sdotee/sdk.php) | [`sdotee/sdk`](https://packagist.org/packages/sdotee/sdk) (Packagist) | PHP 8.1 及以上 |
| .NET / C# | [sdotee/sdk.cs](https://github.com/sdotee/sdk.cs) | `see.sdk` | .NET 8 或 .NET 10 |

## 安装

### TypeScript / JavaScript

```bash
npm i see-sdk
```

### Go

```bash
go get github.com/sdotee/sdk.go
```

### Python

```bash
pip install see-sdk
```

### Rust

```bash
cargo add see-sdk
```

### Swift

在 `Package.swift` 中添加依赖，再把 `see-sdk` product 添加到 target，然后 `import SeeSDK`：

```swift
.package(url: "https://github.com/sdotee/sdk.swift", from: "1.0.0")
```

### Java

从源码构建并安装 SDK：

```bash
git clone https://github.com/sdotee/sdk.java see-java-sdk
cd see-java-sdk
mvn clean install
```

然后添加依赖：

```xml
<dependency>
    <groupId>dev.s.ee</groupId>
    <artifactId>see-java-sdk</artifactId>
    <version>1.3.0</version>
</dependency>
```

### PHP

```bash
composer require sdotee/sdk
```

### .NET / C#

安装方式请参阅 [sdk.cs README](https://github.com/sdotee/sdk.cs)。

## 认证

所有 SDK 都使用您在 **[工具 > API 密钥](https://s.ee/user/developers/)** 中获取的 API 密钥。请从 `SEE_API_KEY` 等环境变量或密钥管理服务中读取，不要写死在代码里。
