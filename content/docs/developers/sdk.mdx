Use an official SDK to call the [S.EE API](/docs/developers/api/) from your application. Each repository's README has full usage examples. Coverage of newer endpoints differs between SDKs, so check the README of the one you pick.

## Official SDKs

| Language | Repository | Package | Requirements |
|----------|------------|---------|--------------|
| TypeScript / JavaScript | [sdotee/sdk.ts](https://github.com/sdotee/sdk.ts) | [`see-sdk`](https://www.npmjs.com/package/see-sdk) on npm | |
| Go | [sdotee/sdk.go](https://github.com/sdotee/sdk.go) | `github.com/sdotee/sdk.go` | |
| Python | [sdotee/sdk.py](https://github.com/sdotee/sdk.py) | [`see-sdk`](https://pypi.org/project/see-sdk/) on PyPI | Python 3.11+ |
| Rust | [sdotee/sdk.rs](https://github.com/sdotee/sdk.rs) | [`see-sdk`](https://crates.io/crates/see-sdk) on crates.io | |
| Swift | [sdotee/sdk.swift](https://github.com/sdotee/sdk.swift) | Swift Package Manager | Swift 6+ |
| Java | [sdotee/sdk.java](https://github.com/sdotee/sdk.java) | `dev.s.ee:see-java-sdk` | Java 17+ |
| PHP | [sdotee/sdk.php](https://github.com/sdotee/sdk.php) | [`sdotee/sdk`](https://packagist.org/packages/sdotee/sdk) on Packagist | PHP 8.1+ |
| .NET / C# | [sdotee/sdk.cs](https://github.com/sdotee/sdk.cs) | `see.sdk` | .NET 8 or .NET 10 |

## Installation

### TypeScript / JavaScript

```bash
npm i see-sdk
```

### Go

```bash
go get github.com/sdotee/sdk.go
```

### Python

```bash
pip install see-sdk
```

### Rust

```bash
cargo add see-sdk
```

### Swift

Add the package to `Package.swift`, then add the `see-sdk` product to your target and `import SeeSDK`:

```swift
.package(url: "https://github.com/sdotee/sdk.swift", from: "1.0.0")
```

### Java

Build and install the SDK from source:

```bash
git clone https://github.com/sdotee/sdk.java see-java-sdk
cd see-java-sdk
mvn clean install
```

Then add the dependency:

```xml
<dependency>
    <groupId>dev.s.ee</groupId>
    <artifactId>see-java-sdk</artifactId>
    <version>1.3.0</version>
</dependency>
```

### PHP

```bash
composer require sdotee/sdk
```

### .NET / C#

See the [sdk.cs README](https://github.com/sdotee/sdk.cs) for installation.

## Authentication

Every SDK takes your API key from **[Tools > API Token](https://s.ee/user/developers/)**. Load it from an environment variable such as `SEE_API_KEY` or your secret manager instead of hardcoding it.
