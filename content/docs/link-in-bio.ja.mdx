## 概要

バイオページは、Linktree のような個人向けランディングページで、すべてのリンクとソーシャルプロフィールを 1 つの短い URL にまとめられます。ソーシャルメディアのプロフィール欄など、リンクを 1 つしか掲載できない場所に最適です。

実際の例として、公式バイオページ [s.ee/see](https://s.ee/see) をご覧ください。

---

## バイオページを作成する

1. [https://s.ee/user/dashboard](https://s.ee/user/dashboard) にログインします
2. 左サイドバーの **リンク管理 > バイオ** をクリックするか、[https://s.ee/user/bio/](https://s.ee/user/bio/) に直接アクセスします
3. **バイオページを作成** をクリックします
4. 必要事項を入力します
   - **タイトル** - ブラウザーのタブに表示されるページタイトルです
   - **ドメイン** - バイオページに使用するドメインを選択します
   - **エイリアス** - URL の一部になるハンドル名です（例: `s.ee/you`）
5. **作成** をクリックします

> **重要:** **ドメイン** と **エイリアス** は作成後に変更できません。別のドメインやエイリアスを使用したい場合は、バイオページを削除して新しく作成してください。

作成後、バイオページの **... > 編集** をクリックしてカスタマイズできます。

## ページ設定

### 基本設定

| オプション | 説明 |
|--------|-------------|
| タイトル | ブラウザーのタブに表示されるページタイトルです |
| 氏名 | ページに表示される名前です。ご自身の名前のほか、組織名も使用できます |
| アバター | カスタムアバターをアップロードできます。設定しない場合は [Gravatar](https://gravatar.com) が使用されます |
| 説明 | ページに表示される短い自己紹介です |
| メールアドレス | メールアドレスをアイコン付きでページに表示します |

### 外観

| オプション | 説明 |
|--------|-------------|
| レイアウトスタイル | **リスト** と **グリッド** のレイアウトから選択できます |
| ページテーマ | 組み込みテーマを選択できます。利用できるテーマは、選択したレイアウトによって異なります |
| カラーモード | **ライト** または **ダーク** を選択できます。一部のダークテーマは配色が 1 種類のみで、どちらのモードでも同じ見た目になります |
| 背景画像 | カスタム背景画像をアップロードできます。一部のテーマでは背景が固定されており変更できません |
| 背景色 | カスタム背景色を設定できます。カスタム背景画像とは併用できず、一部のテーマでは背景色が固定されています |

### コンテンツ

| オプション | 説明 |
|--------|-------------|
| RSSフィード | RSS/Atom フィードへのリンクを表示します。最新エントリー（最大 5 件）の表示オプションもあります |
| Mastodonプロフィール | Mastodon プロフィールへのリンクを表示します。最新投稿（最大 5 件）の表示オプションもあります |
| カスタムリンク | 最大 10 件のリンクを追加できます。各リンクには任意でアイコンと説明を設定でき、アイコンと説明を表示するかどうかも選択できます |

## アプリ連携

OAuth でソーシャルアカウントを連携すると、バイオページに表示できます。連携したアカウントは、アバターの下にアイコンとして表示されます。

| プラットフォーム | 最新コンテンツ（グリッドレイアウトのみ） |
|----------|-----------------------------------|
| X | 最新の投稿を表示します |
| YouTube | 最新の動画を表示します |
| GitHub | 選択したリポジトリを表示します |

> **注意:** 連携アカウントの最新コンテンツは、**グリッド** レイアウトでのみ表示されます。**リスト** レイアウトでは、プロフィールアイコンのみ表示されます。

## カスタムドメイン

ご自身の[カスタムドメイン](/docs/ja/custom-domains)でバイオページを公開する方法は 2 つあります。

- **ルートドメイン** - **ルートドメインのバイオページとして設定** を有効にすると、ドメインのルート（例: `example.com`）で直接バイオページを公開できます
- **パスベース** - ドメインのパス（例: `example.com/you`）でバイオページを公開できます

## アナリティクス

バイオページでは、[短縮リンク](/docs/ja/links)と同じアナリティクスを利用できます。ダッシュボードから訪問数やトラフィックの詳細を確認できます。

---

## バイオページの管理

- **編集** - **... > 編集** をクリックすると、ドメインとエイリアス以外のすべての設定を変更できます
- **アーカイブ** - 再度有効化するまで、バイオページを訪問者から一時的に非表示にします
- **削除** - バイオページを完全に削除し、そのエイリアスを新しいページで使用できるようにします
