[Shortshare](https://shortshare.app/) 是一款支持自定义短网址 API 的短网址应用。把 S.EE 设置为自定义短网址服务后，就可以在应用内生成 S.EE 短网址，也可以用 Shortshare 的快捷指令动作直接生成。

<Callout type="warn">
据 Shortshare 官网说明，Shortshare 已不再提供 iOS 和 macOS 版本：应用无法继续更新，也不兼容 iOS 27 / macOS 27 及以上版本。已购买的用户可以在 [shortshare.app](https://shortshare.app/) 下载适配 macOS 27+ 的修复版。Windows 版仍可在 Microsoft Store 获取。
</Callout>

---

## 获取 API 密钥

在 **[工具 > API 密钥](https://s.ee/user/developers/)** 复制您的 API 密钥。

---

## 在 Shortshare 中设置 S.EE

1. **Url Shortener** 类型选择 **Custom**
2. 在 **Configure** 中填写：

| 设置项 | 内容 |
|--------|------|
| Endpoint | `https://s.ee/api/v1/shorten` |
| URL Parameter | 选择 **GET**，填写 `url` |
| Auth Parameter | 选择 **Header**。第一个框填 `Authorization`，第二个框填 `Bearer YOUR_API_KEY` |
| Response Format | 选择 **Plaintext**，框内留空 |

把 `YOUR_API_KEY` 换成您的密钥，`Bearer` 后面要保留一个空格。

S.EE 以纯文本返回短网址，Shortshare 可以直接使用。短网址会创建在您账号的默认域名下。

<Callout type="warn">
不要公开分享您的 API 密钥。
</Callout>

---

## 故障排查

| 问题 | 解决方法 |
|------|----------|
| 401 错误 | 检查 `Authorization` 的值和 API 密钥是否正确 |
| 没有返回短网址 | 确认 **Response Format** 选择了 **Plaintext**，且框内为空 |
