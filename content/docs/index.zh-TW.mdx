## 什麼是 S.EE？

S.EE 是一個連結管理平台，可建立短網址、產生 QR Code 和分享內容，並內建資料分析與自訂網域支援。平台包含：

- **[S.EE 短網址](https://s.ee/user/links/)** - 建立支援自訂網域、密碼保護和智慧定向的短網址
- **[S.EE 個人首頁](https://s.ee/user/bio/)** - 建立個人首頁，將您的連結和社群個人檔案集中在一個短網址
- **[S.EE QR Code](https://s.ee/user/qr/)** - 產生可自訂且附帶資料分析的 QR Code
- **[S.EE 文字分享](https://s.ee/user/text/)** - 透過短網址分享純文字、程式碼片段和 Markdown
- **[S.EE 檔案分享](https://s.ee/user/files/)** - 上傳檔案並透過短網址分享
- **[S.EE 圖床](https://s.ee/user/images/)** - 上傳圖片並取得分享連結

## 主要功能

### 短網址管理

短網址支援以下設定：
- 自訂短碼和自訂網域
- 密碼保護
- 過期時間
- 按地區、裝置或語言進行定向
- UTM 參數
- 參數傳遞

### 個人首頁

[個人首頁](/docs/zh-TW/link-in-bio)支援：
- 將所有連結和社群個人檔案集中在一個頁面
- 清單或網格版面，附帶內建主題
- X、YouTube 和 GitHub 整合
- 託管於 s.ee、b.ee 或您自己的網域

### QR Code

QR Code 支援：
- 自訂顏色和 Logo
- 下載為 PNG、SVG 或 PDF
- 內建資料分析

### 文字分享

文字分享支援：
- 純文字、程式碼片段和 Markdown
- 程式碼語法醒目提示
- 密碼保護與過期時間
- 原始文字端點，便於下載

### 檔案分享

檔案分享支援：
- 拖放、貼上或上傳資料夾
- 自訂網域和自訂短碼
- 為私人檔案設定密碼和過期時間
- 直接下載連結

### 圖床

圖片託管支援：
- 拖放、貼上或上傳資料夾
- 從剪貼簿貼上時自動最佳化圖片
- 直接圖片連結便於嵌入

### 資料分析

查看連結瀏覽資料：
- 點擊次數
- 地理位置資料
- 裝置與瀏覽器資訊
- 來源
