[Dropshare](https://dropshare.app/) for Mac 可以用自定义短网址服务缩短上传后的链接。连接 S.EE 有两种方式：S.EE API 简单模式，或 [YOURLS 兼容 API](/docs/zh-CN/yourls/)。

另请参阅：[Dropshare 自定义短网址设置指南](https://kb.dropshare.app/how-to/how-to-set-up-a-custom-url-shortener.html)

---

## 获取 API 密钥

在 **[工具 > API 密钥](https://s.ee/user/developers/)** 复制您的 API 密钥。

---

## 打开短网址设置

1. 打开 Dropshare 的 **Preferences**，选择 **Uploads** 标签页
2. 短网址服务选择 **Custom (advanced)**
3. 按下面任一方式填写

---

## 方式一：S.EE API 简单模式

| 字段 | 内容 |
|------|------|
| Endpoint | `https://s.ee/api/v1/shorten` |
| URL Parameter | `GET`，参数名 `url` |
| Additional Parameters | 留空 |
| Auth. Parameter | `Header`，参数名 `Authorization`，值为您的 API 密钥 |
| Response Format | Plaintext |

[简单模式](/docs/zh-CN/api/CreateShortUrlSimpleMode)的参数都放在查询字符串中，请求成功时只返回纯文本的短网址。短网址默认创建在 `s.ee` 域名下；如果要使用其他域名，在 Endpoint 后加上该域名：`https://s.ee/api/v1/shorten?domain=go.example.com`。

---

## 方式二：YOURLS 兼容 API

| 字段 | 内容 |
|------|------|
| Endpoint | `https://s.ee/api/v1/yourls?action=shorturl&format=json` |
| URL Parameter | `GET`，参数名 `url` |
| Additional Parameters | 留空 |
| Auth. Parameter | `GET`，参数名 `signature`，值为您的 API 密钥 |
| Response Format | JSON，键名 `shorturl` |

如果您在 Dropshare 中已经配置过 YOURLS，只需把 Endpoint 改为 S.EE 的地址，并在 `signature` 中填写 S.EE API 密钥。这个 API 生成的短网址固定使用 `s.ee` 域名。

<Callout type="warn">
不要公开分享您的 API 密钥。
</Callout>

---

## 测试

点击 **Test**，Dropshare 会缩短一个示例网址，并检查能否从响应中读取短网址。

---

## 故障排查

| 问题 | 解决方法 |
|------|----------|
| 401 错误 | 检查 **Auth. Parameter** 中的 API 密钥 |
| 测试时读取不到短网址 | 检查 **Response Format**：方式一选 Plaintext；方式二选 JSON、键名 `shorturl` |

Dropshare 会在日志中记录每次请求收到的响应，参见 [如何获取日志文件](https://kb.dropshare.app/faq/how-do-i-get-the-log-files.html)。
