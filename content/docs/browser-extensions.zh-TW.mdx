使用 S.EE 瀏覽器擴充套件，可直接在 Chrome、Firefox 和 Edge 中建立短網址、分享文字和上傳檔案。

原始碼：[GitHub](https://github.com/sdotee/browser-extensions)。

## 功能

| 功能 | 說明 |
|---------|-------------|
| URL 縮短 | 一鍵縮短任意 URL，支援自訂別名和多個網域選項 |
| 文字分享 | 分享文字和程式碼片段，支援語法醒目提示 |
| 檔案分享 | 支援批次上傳檔案並追蹤進度 |
| 匯出格式 | 可將結果複製為 Plain URL、Markdown、HTML 或 BBCode |
| QR 碼 產生 | 為任意短網址產生 QR 碼 |
| QR 碼 匯出 | 將 QR 碼 下載為 PNG、SVG 或 PDF 格式（512x512） |
| 右鍵選單 | 縮短頁面 / 連結、顯示 QR 碼、分享選取的文字、上傳圖片 |
| 歷史紀錄管理 | 依分頁區分 URL、文字和檔案歷史，並支援批次刪除 |
| 自動儲存草稿 | 自動儲存輸入內容，下次開啟時可繼續編輯 |
| 自動複製 | 自動將結果複製到剪貼簿 |
| 深色 / 淺色模式 | 自動偵測主題，並支援手動切換 |
| 桌面通知 | 透過右鍵選單執行操作後，接收完成通知 |
| 跨瀏覽器 | 支援 Chrome（MV3）、Firefox（MV3）和 Edge |
