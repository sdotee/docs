S.EE runs several free URL shorteners. Each one only shortens links to the sites listed next to it, subdomains included. You don't need an account, and the short links never expire.

## Limitations

| Feature | Free Services | S.EE Membership |
|---------|---------------|-----------------|
| Analytics | Not available | Full statistics |
| Custom slugs | Not available | Fully customizable |
| Supported domains | Limited | Any domain |
| Account | Not required | Created when you buy a plan |

<Callout type="info">
If you need analytics, custom slugs, or support for any domain, consider upgrading to a [S.EE membership](https://s.ee/user/pricing/).
