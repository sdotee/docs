## 概览

个人页面（Bio Page）是一个类似 Linktree 的个人落地页，将您的所有链接和社交资料汇集在一个短网址背后。非常适合社交媒体简介，以及任何只能放一个链接的地方。

想看实际效果，可以访问我们的官方个人页面 [s.ee/see](https://s.ee/see)。

---

## 创建个人页面

1. 登录 [https://s.ee/user/dashboard](https://s.ee/user/dashboard)
2. 在左侧边栏点击 **链接管理 > 个人主页**，或直接前往 [https://s.ee/user/bio/](https://s.ee/user/bio/)
3. 点击 **创建个人页面**
4. 填写以下信息：
   - **标题** - 显示在浏览器标签页上的页面标题
   - **域名** - 选择您个人页面使用的域名
   - **别名** - 您的用户名，会成为 URL 的一部分（例如 `s.ee/you`）
5. 点击 **创建**

> **重要提示：** **域名** 和 **别名** 在创建后无法修改。如需使用其他域名或别名，请删除该个人页面并重新创建。

创建完成后，点击个人页面上的 **... > 编辑** 即可进行自定义。

## 页面设置

### 基础信息

| 选项 | 说明 |
|--------|-------------|
| 标题 | 显示在浏览器标签页上的页面标题 |
| 全名 | 显示在页面上的名称，可以是您的姓名或组织名称 |
| 头像 | 上传自定义头像。如果未设置，将使用您的 [Gravatar](https://gravatar.com) |
| 描述 | 显示在页面上的简短介绍 |
| 邮箱 | 在页面上以图标形式展示您的邮箱地址 |

### 外观

| 选项 | 说明 |
|--------|-------------|
| 布局样式 | 在 **列表** 和 **网格** 两种布局之间选择 |
| 页面主题 | 选择内置主题。可用主题取决于所选布局 |
| 配色模式 | 选择 **浅色** 或 **深色**。部分深色主题只有一种配色方案，在两种模式下显示效果相同 |
| 背景图片 | 上传自定义背景图片。部分主题的背景是固定的，无法修改 |
| 背景颜色 | 设置自定义背景颜色。背景颜色与自定义背景图片冲突，且部分主题的背景颜色是固定的 |

### 内容

| 选项 | 说明 |
|--------|-------------|
| RSS 订阅 | 展示您的 RSS/Atom 订阅链接，并可选择显示其最新条目（最多 5 条） |
| Mastodon 主页 | 展示您的 Mastodon 主页链接，并可选择显示您的最新嘟文（最多 5 条） |
| 自定义链接 | 添加最多 10 个链接，每个链接可附带图标和描述。您可以选择是否显示图标和描述 |

## 应用关联

通过 OAuth 关联社交账号，即可在您的个人页面上展示它们。已关联的账号会以图标形式显示在头像下方。

| 平台 | 最新内容（仅限网格布局） |
|----------|-----------------------------------|
| X | 展示您的最新帖子 |
| YouTube | 展示您的最新视频 |
| GitHub | 展示您选择的仓库 |

> **注意：** 已关联账号的最新内容仅在 **网格** 布局下显示。在 **列表** 布局下，只显示账号图标。

## 自定义域名

您可以通过以下两种方式在自己的[自定义域名](/docs/zh-CN/custom-domains)上托管个人页面：

- **根域名** - 启用 **设为根域名的个人页面** 后，直接在域名根路径（例如 `example.com`）提供个人页面
- **路径方式** - 在域名的某个路径下（例如 `example.com/you`）提供个人页面

## 数据分析

个人页面拥有与[短链接](/docs/zh-CN/links)相同的数据分析功能。您可以在控制台中查看访问量和流量详情。

---

## 管理个人页面

- **编辑** - 点击 **... > 编辑** 可修改除域名和别名以外的所有设置
- **归档** - 暂时对访客隐藏您的个人页面，直到您再次激活
- **删除** - 永久删除该个人页面，并释放其别名以供新页面使用
