## 檔案儲存和 CDN 網域

這些內部網域由 S.EE 用於檔案儲存、使用者上傳內容分發和 CDN 加速。它們為整個平台提供靜態資源、快取內容和使用者上傳的內容，不供使用者直接選用，但在存取託管檔案或媒體時，可能會出現在 URL 中。

| 網域 | 說明 | TLD | DNS | CDN | DNSSEC | HSTS |
|--------|-------------|-----|-----|-----|--------|------|
| [**see.you**](https://see.you) | 面向使用者的檔案下載和共享媒體連結主網域。 | [.you](https://www.iana.org/domains/root/db/you.html) | Cloudflare | Cloudflare | [檢視](https://dnssec-analyzer.verisignlabs.com/see.you) | ✓ |
| [**seecdn.com**](https://seecdn.com) | 用於全球靜態資源和快取內容加速分發的主 CDN 網域。 | [.com](https://www.iana.org/domains/root/db/com.html) | Cloudflare | Cloudflare | [檢視](https://dnssec-analyzer.verisignlabs.com/seecdn.com) | ✓ |
| [**seecdn.net**](https://seecdn.net) | 次級 CDN 網域，用於高可用和故障切換的冗餘內容分發。 | [.net](https://www.iana.org/domains/root/db/net.html) | Cloudflare | Cloudflare | [檢視](https://dnssec-analyzer.verisignlabs.com/seecdn.net) | ✓ |
| [**seeusercontent.com**](https://seeusercontent.com) | 用於在沙箱環境中提供使用者上傳內容的專用網域，將使用者檔案與主要應用程式隔離以增強安全性。 | [.com](https://www.iana.org/domains/root/db/com.html) | Cloudflare | Cloudflare | [檢視](https://dnssec-analyzer.verisignlabs.com/seeusercontent.com) | ✓ |
