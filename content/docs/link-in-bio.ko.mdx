## 개요

바이오 페이지는 Linktree 와 비슷한 개인 랜딩 페이지로, 모든 링크와 소셜 프로필을 하나의 단축 URL 뒤에 모아 줍니다. 소셜 미디어 프로필처럼 링크를 하나만 넣을 수 있는 곳에 적합합니다.

실제 예시는 공식 바이오 페이지 [s.ee/see](https://s.ee/see) 를 참고해 주세요.

---

## 바이오 페이지 만들기

1. [https://s.ee/user/dashboard](https://s.ee/user/dashboard) 에 로그인합니다
2. 왼쪽 사이드바에서 **링크 관리 > 바이오** 를 클릭하거나 [https://s.ee/user/bio/](https://s.ee/user/bio/) 로 바로 이동합니다
3. **Bio 페이지 생성** 을 클릭합니다
4. 다음 정보를 입력합니다
   - **제목** - 브라우저 탭에 표시되는 페이지 제목입니다
   - **도메인** - 바이오 페이지에 사용할 도메인을 선택합니다
   - **별칭** - 사용자의 핸들로, URL 의 일부가 됩니다 (예: `s.ee/you`)
5. **생성** 을 클릭합니다

> **중요:** **도메인** 과 **별칭** 은 생성 후 변경할 수 없습니다. 다른 도메인이나 별칭을 사용하려면 바이오 페이지를 삭제하고 새로 만들어야 합니다.

생성이 완료되면 바이오 페이지에서 **... > 편집** 을 클릭해 페이지를 꾸밀 수 있습니다.

## 페이지 설정

### 기본 정보

| Option | Description |
|--------|-------------|
| 제목 | 브라우저 탭에 표시되는 페이지 제목입니다 |
| 전체 이름 | 페이지에 표시되는 이름입니다. 본인 이름이나 조직 이름을 사용할 수 있습니다 |
| 아바타 | 커스텀 아바타를 업로드합니다. 설정하지 않으면 [Gravatar](https://gravatar.com) 가 사용됩니다 |
| 설명 | 페이지에 표시되는 짧은 소개 문구입니다 |
| 이메일 | 페이지에 이메일 주소를 아이콘과 함께 표시합니다 |

### 모양

| Option | Description |
|--------|-------------|
| 레이아웃 스타일 | **리스트** 와 **그리드** 레이아웃 중에서 선택합니다 |
| 페이지 테마 | 기본 제공 테마를 선택합니다. 사용 가능한 테마는 선택한 레이아웃에 따라 다릅니다 |
| 색상 모드 | **라이트** 또는 **다크** 를 선택합니다. 일부 다크 테마는 색상 구성이 하나뿐이어서 어느 모드에서도 동일하게 보입니다 |
| 배경 이미지 | 커스텀 배경 이미지를 업로드합니다. 일부 테마에서는 배경이 고정되어 변경할 수 없습니다 |
| 배경 색상 | 커스텀 배경 색상을 설정합니다. 커스텀 배경 이미지와 함께 사용할 수 없으며, 일부 테마에서는 배경 색상이 고정되어 있습니다 |

### 콘텐츠

| Option | Description |
|--------|-------------|
| RSS 피드 | RSS/Atom 피드 링크를 표시하고, 최신 항목(최대 5개)을 함께 표시하도록 설정할 수 있습니다 |
| Mastodon 프로필 | Mastodon 프로필 링크를 표시하고, 최신 게시물(최대 5개)을 함께 표시하도록 설정할 수 있습니다 |
| 커스텀 링크 | 최대 10개의 링크를 추가할 수 있으며, 각 링크에 아이콘과 설명을 선택적으로 넣을 수 있습니다. 아이콘과 설명 표시 여부도 선택할 수 있습니다 |

## 소셜 미디어

OAuth 로 소셜 계정을 연결해 바이오 페이지에 표시할 수 있습니다. 연결된 계정은 아바타 아래에 아이콘으로 나타납니다.

| Platform | Latest Content (Grid layout only) |
|----------|-----------------------------------|
| X | 최신 게시물을 표시합니다 |
| YouTube | 최신 동영상을 표시합니다 |
| GitHub | 선택한 저장소를 표시합니다 |

> **참고:** 연결된 계정의 최신 콘텐츠는 **그리드** 레이아웃에서만 표시됩니다. **리스트** 레이아웃에서는 프로필 아이콘만 표시됩니다.

## 인증

바이오 페이지에 인증 배지를 신청할 수 있습니다 — 개인용 블루 체크 또는 조직용 골드 체크가 있습니다. 자세한 내용과 신청 방법은 [바이오 페이지 인증](/docs/ko/link-in-bio-verification)을 참고해 주세요.

---

## 커스텀 도메인

자신의 [커스텀 도메인](/docs/ko/custom-domains)에서 바이오 페이지를 호스팅하는 방법은 두 가지입니다.

- **루트 도메인** - **루트 도메인의 Bio 페이지로 설정** 을 활성화해 도메인 루트(예: `example.com`)에서 바이오 페이지를 바로 제공합니다
- **경로 기반** - 도메인의 경로(예: `example.com/you`)에서 바이오 페이지를 제공합니다

## 분석

바이오 페이지는 [단축 링크](/docs/ko/links)와 동일한 분석 기능을 제공합니다. 대시보드에서 방문 수와 트래픽 세부 정보를 확인할 수 있습니다.

---

## 바이오 페이지 관리

- **편집** - **... > 편집** 을 클릭해 도메인과 별칭을 제외한 모든 설정을 변경할 수 있습니다
- **보관** - 다시 활성화할 때까지 바이오 페이지를 방문자에게 일시적으로 숨깁니다
- **삭제** - 바이오 페이지를 영구적으로 제거하고, 해당 별칭을 새 페이지에서 사용할 수 있도록 해제합니다
