## Обзор

Bio-страница — это персональная посадочная страница, похожая на Linktree, которая собирает все ваши ссылки и профили соцсетей за одним коротким URL. Идеально подходит для био в соцсетях и любых мест, где можно указать только одну ссылку.

Живой пример — наша официальная bio-страница [s.ee/see](https://s.ee/see).

---

## Создание bio-страницы

1. Войдите в [https://s.ee/user/dashboard](https://s.ee/user/dashboard)
2. Нажмите **Управление ссылками > Био** в левой боковой панели или сразу откройте [https://s.ee/user/bio/](https://s.ee/user/bio/)
3. Нажмите **Создать bio-страницу**
4. Заполните поля:
   - **Название** - заголовок страницы, отображаемый во вкладке браузера
   - **Домен** - выберите домен для вашей bio-страницы
   - **Алиас** - ваш никнейм, который становится частью URL (например, `s.ee/you`)
5. Нажмите **Создать**

> **Важно:** Поля **Домен** и **Алиас** нельзя изменить после создания. Чтобы использовать другой домен или алиас, удалите bio-страницу и создайте новую.

После создания нажмите **... > Изменить** на вашей bio-странице, чтобы настроить её.

## Настройки страницы

### Основные

| Параметр | Описание |
|--------|----------|
| Название | Заголовок страницы, отображаемый во вкладке браузера |
| Полное имя | Имя, отображаемое на странице. Это может быть ваше собственное имя или название организации |
| Аватар | Загрузите собственный аватар. Если он не задан, используется ваш [Gravatar](https://gravatar.com) |
| Описание | Краткое представление, отображаемое на странице |
| Электронная почта | Показывает ваш адрес электронной почты со значком на странице |

### Внешний вид

| Параметр | Описание |
|--------|----------|
| Стиль макета | Выберите между макетами **Список** и **Сетка** |
| Page theme | Выберите встроенную тему. Доступные темы зависят от выбранного макета |
| Color mode | Выберите режим **Светлая** или **Тёмная**. У некоторых тёмных тем есть только одна цветовая схема, и они выглядят одинаково в обоих режимах |
| Фоновое изображение | Загрузите собственное фоновое изображение. В некоторых темах фон фиксирован и не может быть изменён |
| Цвет фона | Задайте собственный цвет фона. Он конфликтует с пользовательским фоновым изображением, а в некоторых темах цвет фона фиксирован |

### Содержимое

| Параметр | Описание |
|--------|----------|
| RSS-лента | Показывает ссылку на вашу ленту RSS/Atom с возможностью отображать последние записи (до 5) |
| Профиль Mastodon | Показывает ссылку на ваш профиль Mastodon с возможностью отображать последние посты (до 5) |
| Собственные ссылки | Добавьте до 10 ссылок, каждая с необязательным значком и описанием. Вы можете выбирать, отображать ли значки и описания |

## Подключения приложений

Подключите аккаунты соцсетей через OAuth, чтобы показывать их на bio-странице. Подключённые аккаунты отображаются в виде значков под аватаром.

| Платформа | Последний контент (только макет «Сетка») |
|----------|-----------------------------------|
| X | Показывает ваши последние посты |
| YouTube | Показывает ваши последние видео |
| GitHub | Показывает выбранные вами репозитории |

> **Примечание:** Последний контент подключённых аккаунтов отображается только в макете **Сетка**. В макете **Список** показываются только значки профилей.

## Пользовательские домены

Вы можете разместить bio-страницу на собственном [пользовательском домене](/docs/ru/custom-domains) двумя способами:

- **Корневой домен** - обслуживайте bio-страницу непосредственно в корне вашего домена (например, `example.com`), включив параметр **Сделать bio-страницей для корневого домена**
- **По пути** - обслуживайте bio-страницу по пути на вашем домене (например, `example.com/you`)

---

|--------|--------------|

## Аналитика

Bio-страницы имеют ту же аналитику, что и [короткие ссылки](/docs/ru/links). Вы можете просматривать посещения и детали трафика в панели управления.

---

## Управление bio-страницами

- **Изменить** - нажмите **... > Изменить**, чтобы изменить любые настройки, кроме домена и алиаса
- **Архивировать** - временно скройте bio-страницу от посетителей, пока не активируете её снова
- **Удалить** - удалите bio-страницу навсегда и освободите её алиас для новой страницы
