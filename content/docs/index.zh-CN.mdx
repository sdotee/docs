## 什么是 S.EE？

S.EE 是一个链接管理平台，可创建短网址、生成二维码和分享内容，并内置数据分析和自定义域名支持。平台包含：

- **[S.EE 短网址](https://s.ee/user/links/)** - 创建支持自定义域名、密码保护和智能定向的短网址
- **[S.EE 个人主页](https://s.ee/user/bio/)** - 创建个人主页，用一个短网址汇集您的所有链接和社交资料
- **[S.EE 二维码](https://s.ee/user/qr/)** - 生成可自定义且带数据分析的二维码
- **[S.EE 文本分享](https://s.ee/user/text/)** - 通过短网址分享纯文本、代码片段和 Markdown
- **[S.EE 文件分享](https://s.ee/user/files/)** - 上传文件并通过短网址分享
- **[S.EE 图片托管](https://s.ee/user/images/)** - 上传图片并获取分享链接

## 主要功能

### 短网址管理

短网址支持以下设置：
- 自定义别名和自定义域名
- 密码保护
- 过期时间
- 按地区、设备或语言进行定向
- UTM 参数
- 参数传递

### 个人主页

[个人主页](/docs/zh-CN/link-in-bio)支持：
- 在一个页面上汇集您的所有链接和社交资料
- 列表或网格布局，搭配内置主题
- X、YouTube 和 GitHub 应用关联
- 托管在 s.ee、b.ee 或您自己的域名上

### 二维码

二维码支持：
- 自定义颜色和 Logo
- 下载为 PNG、SVG 或 PDF
- 内置数据分析

### 文本分享

文本分享支持：
- 纯文本、代码片段和 Markdown
- 代码语法高亮
- 密码保护与过期时间
- 原始文本接口，便于下载

### 文件分享

文件分享支持：
- 拖拽、粘贴或上传文件夹
- 自定义域名和自定义别名
- 为私密文件设置密码和过期时间
- 直接下载链接

### 图片托管

图片托管支持：
- 拖拽、粘贴或上传文件夹
- 从剪贴板粘贴时自动优化图片
- 直接图片链接便于嵌入

### 数据分析

查看链接访问数据：
- 点击量
- 地理位置数据
- 设备与浏览器信息
- 来源
