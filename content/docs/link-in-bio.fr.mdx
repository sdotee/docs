## Vue d’ensemble

Une page bio est une page d’accueil personnelle, similaire à Linktree, qui regroupe tous vos liens et profils sociaux derrière une seule URL courte. Idéale pour les bios de réseaux sociaux et partout où vous ne disposez que d’un seul lien.

Pour un exemple en ligne, consultez notre page bio officielle sur [s.ee/see](https://s.ee/see).

---

## Créer une page bio

1. Connectez-vous sur [https://s.ee/user/dashboard](https://s.ee/user/dashboard)
2. Cliquez sur **Gestion des liens > Bio** dans la barre latérale gauche ou accédez directement à [https://s.ee/user/bio/](https://s.ee/user/bio/)
3. Cliquez sur **Créer une page bio**
4. Renseignez les détails :
   - **Titre** - Le titre de la page affiché dans l’onglet du navigateur
   - **Domaine** - Sélectionnez le domaine de votre page bio
   - **Alias** - Votre identifiant, qui devient une partie de l’URL (par ex. `s.ee/you`)
5. Cliquez sur **Créer**

> **Important :** Le **Domaine** et l’**Alias** ne peuvent pas être modifiés après la création. Pour utiliser un autre domaine ou alias, supprimez la page bio et créez-en une nouvelle.

Une fois la page créée, cliquez sur **... > Modifier** sur votre page bio pour la personnaliser.

## Paramètres de la page

### Informations de base

| Option | Description |
|--------|-------------|
| Titre | Le titre de la page affiché dans l’onglet du navigateur |
| Nom complet | Le nom affiché sur la page. Il peut s’agir de votre propre nom ou du nom d’une organisation |
| Avatar | Téléversez un avatar personnalisé. Si vous n’en définissez pas, votre [Gravatar](https://gravatar.com) est utilisé |
| Description | Une courte présentation affichée sur la page |
| E-mail | Affichez votre adresse e-mail avec une icône sur la page |

### Apparence

| Option | Description |
|--------|-------------|
| Style de mise en page | Choisissez entre les mises en page **Liste** et **Grille** |
| Thème de page | Choisissez un thème intégré. Les thèmes disponibles dépendent de la mise en page sélectionnée |
| Mode couleur | Choisissez **Clair** ou **Sombre**. Certains thèmes sombres n’ont qu’un seul jeu de couleurs et s’affichent de la même façon dans les deux modes |
| Image d'arrière-plan | Téléversez une image d’arrière-plan personnalisée. Sur certains thèmes, l’arrière-plan est fixe et ne peut pas être modifié |
| Couleur d'arrière-plan | Définissez une couleur d’arrière-plan personnalisée. Elle entre en conflit avec une image d’arrière-plan personnalisée, et sur certains thèmes la couleur d’arrière-plan est fixe |

### Contenu

| Option | Description |
|--------|-------------|
| Flux RSS | Affichez un lien vers votre flux RSS/Atom, avec une option pour afficher ses dernières entrées (jusqu’à 5) |
| Profil Mastodon | Affichez un lien vers votre profil Mastodon, avec une option pour afficher vos dernières publications (jusqu’à 5) |
| Liens personnalisés | Ajoutez jusqu’à 10 liens, chacun avec une icône et une description facultatives. Vous pouvez choisir d’afficher ou non les icônes et les descriptions |

## Connexions d'applications

Connectez vos comptes sociaux avec OAuth pour les afficher sur votre page bio. Les comptes connectés apparaissent sous forme d’icônes sous votre avatar.

| Plateforme | Dernier contenu (mise en page Grille uniquement) |
|----------|-----------------------------------|
| X | Affiche vos dernières publications |
| YouTube | Affiche vos dernières vidéos |
| GitHub | Affiche les dépôts de votre choix |

> **Remarque :** Le dernier contenu des comptes connectés ne s’affiche que dans la mise en page **Grille**. Dans la mise en page **Liste**, seules les icônes de profil sont affichées.

## Domaines personnalisés

Vous pouvez héberger votre page bio sur votre propre [domaine personnalisé](/docs/fr/custom-domains) de deux façons :

- **Domaine racine** - Servez la page bio directement à la racine de votre domaine (par ex. `example.com`) en activant **Définir comme page bio pour le domaine racine**
- **Par chemin** - Servez la page bio sur un chemin de votre domaine (par ex. `example.com/you`)

## Gérer les pages bio

- **Modifier** - Cliquez sur **... > Modifier** pour changer n’importe quel paramètre, à l’exception du domaine et de l’alias
- **Archiver** - Masquez temporairement votre page bio aux visiteurs jusqu’à ce que vous la réactiviez
- **Supprimer** - Supprimez définitivement la page bio et libérez son alias pour une nouvelle page
