## Ikhtisar

Halaman bio adalah landing page pribadi, mirip Linktree, yang menempatkan semua tautan dan profil sosial Anda di balik satu URL pendek. Cocok untuk bio media sosial dan tempat mana pun yang hanya menyediakan satu tautan.

Untuk contoh langsung, lihat halaman bio resmi kami di [s.ee/see](https://s.ee/see).

---

## Buat Halaman Bio

1. Login ke [https://s.ee/user/dashboard](https://s.ee/user/dashboard)
2. Klik **Manajemen Tautan > Bio** di sidebar kiri atau langsung buka [https://s.ee/user/bio/](https://s.ee/user/bio/)
3. Klik **Buat halaman bio**
4. Isi detail berikut:
   - **Title** - Judul halaman yang ditampilkan di tab browser
   - **Domain** - Pilih domain untuk halaman bio Anda
   - **Alias** - Handle Anda, yang menjadi bagian dari URL (mis. `s.ee/you`)
5. Klik **Buat**

> **Penting:** **Domain** dan **Alias** tidak dapat diubah setelah dibuat. Untuk menggunakan domain atau alias yang berbeda, hapus halaman bio tersebut dan buat yang baru.

Setelah dibuat, klik **... > Ubah** pada halaman bio Anda untuk menyesuaikannya.

## Pengaturan Halaman

### Dasar

| Option | Description |
|--------|-------------|
| Title | Judul halaman yang ditampilkan di tab browser |
| Nama lengkap | Nama yang ditampilkan di halaman. Bisa berupa nama Anda sendiri atau nama organisasi |
| Avatar | Unggah avatar kustom. Jika tidak diatur, [Gravatar](https://gravatar.com) Anda akan digunakan |
| Deskripsi | Perkenalan singkat yang ditampilkan di halaman |
| Email | Tampilkan alamat email Anda dengan ikon di halaman |

### Tampilan

| Option | Description |
|--------|-------------|
| Gaya tata letak | Pilih antara tata letak **Daftar** dan **Kisi** |
| Page theme | Pilih tema bawaan. Tema yang tersedia bergantung pada tata letak yang dipilih |
| Color mode | Pilih **Terang** atau **Gelap**. Beberapa tema gelap hanya memiliki satu skema warna dan terlihat sama di kedua mode |
| Gambar latar | Unggah gambar latar kustom. Pada beberapa tema, latar belakangnya tetap dan tidak dapat diubah |
| Warna latar | Atur warna latar kustom. Pengaturan ini bertentangan dengan gambar latar kustom, dan pada beberapa tema warna latarnya tetap |

### Konten

| Option | Description |
|--------|-------------|
| Feed RSS | Tampilkan tautan ke feed RSS/Atom Anda, dengan opsi untuk menampilkan entri terbarunya (hingga 5) |
| Profil Mastodon | Tampilkan tautan ke profil Mastodon Anda, dengan opsi untuk menampilkan postingan terbaru Anda (hingga 5) |
| Tautan kustom | Tambahkan hingga 10 tautan, masing-masing dengan ikon dan deskripsi opsional. Anda dapat memilih apakah ikon dan deskripsi ditampilkan |

## Koneksi Aplikasi

Hubungkan akun sosial dengan OAuth untuk menampilkannya di halaman bio Anda. Akun yang terhubung muncul sebagai ikon di bawah avatar Anda.

| Platform | Latest Content (Grid layout only) |
|----------|-----------------------------------|
| X | Menampilkan postingan terbaru Anda |
| YouTube | Menampilkan video terbaru Anda |
| GitHub | Menampilkan repositori pilihan Anda |

> **Catatan:** Konten terbaru dari akun yang terhubung hanya ditampilkan pada tata letak **Kisi**. Pada tata letak **Daftar**, hanya ikon profil yang ditampilkan.

## Domain Kustom

Anda dapat meng-host halaman bio di [domain kustom](/docs/id/custom-domains) Anda sendiri dengan dua cara:

- **Root domain** - Sajikan halaman bio langsung di root domain Anda (mis. `example.com`) dengan mengaktifkan **Tetapkan sebagai halaman bio untuk root domain**
- **Berbasis path** - Sajikan halaman bio di sebuah path pada domain Anda (mis. `example.com/you`)

## Mengelola Halaman Bio

- **Ubah** - Klik **... > Ubah** untuk mengubah pengaturan apa pun kecuali domain dan alias
- **Arsipkan** - Sembunyikan halaman bio Anda sementara dari pengunjung hingga Anda mengaktifkannya kembali
- **Hapus** - Hapus halaman bio secara permanen dan bebaskan aliasnya untuk halaman baru
