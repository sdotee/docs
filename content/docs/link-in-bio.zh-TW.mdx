## 概覽

個人頁面是一個類似 Linktree 的個人化落地頁，將您所有的連結和社交檔案集中在一個短網址背後。非常適合社交媒體簡介，以及任何只能放一個連結的地方。

想檢視實際範例，請參考我們的官方個人頁面 [s.ee/see](https://s.ee/see)。

---

## 建立個人頁面

1. 登入 [https://s.ee/user/dashboard](https://s.ee/user/dashboard)
2. 在左側邊欄點擊 **連結管理 > 個人頁面**，或直接前往 [https://s.ee/user/bio/](https://s.ee/user/bio/)
3. 點擊 **建立個人頁面**
4. 填寫以下資訊：
   - **標題** - 顯示在瀏覽器分頁上的頁面標題
   - **網域** - 選擇個人頁面使用的網域
   - **別名** - 您的識別名稱，會成為網址的一部分（例如 `s.ee/you`）
5. 點擊 **建立**

> **重要：** **網域** 和 **別名** 在建立後無法修改。如需使用其他網域或別名，請刪除該個人頁面並重新建立。

建立完成後，在您的個人頁面上點擊 **... > 編輯** 即可進行自訂。

## 頁面設定

### 基本資訊

| 選項 | 說明 |
|--------|-------------|
| 標題 | 顯示在瀏覽器分頁上的頁面標題 |
| 全名 | 顯示在頁面上的名稱，可以是您的本名或組織名稱 |
| 頭像 | 上傳自訂頭像。如未設定，將使用您的 [Gravatar](https://gravatar.com) |
| 描述 | 顯示在頁面上的簡短介紹 |
| 電子信箱 | 在頁面上以圖示形式顯示您的電子信箱地址 |

### 外觀

| 選項 | 說明 |
|--------|-------------|
| 版面樣式 | 從 **列表** 和 **網格** 兩種版面中選擇 |
| 頁面主題 | 選擇內建主題。可用主題取決於所選的版面樣式 |
| 配色模式 | 選擇 **淺色** 或 **深色**。部分深色主題只有一種配色，在兩種模式下顯示效果相同 |
| 背景圖片 | 上傳自訂背景圖片。部分主題的背景是固定的，無法更改 |
| 背景顏色 | 設定自訂背景顏色。此選項與自訂背景圖片衝突，且部分主題的背景顏色是固定的 |

### 內容

| 選項 | 說明 |
|--------|-------------|
| RSS 訂閱 | 顯示您的 RSS/Atom 訂閱來源連結，並可選擇顯示其最新文章（最多 5 篇） |
| Mastodon 個人檔案 | 顯示您的 Mastodon 個人檔案連結，並可選擇顯示您的最新貼文（最多 5 篇） |
| 自訂連結 | 新增最多 10 個連結，每個連結可選擇附帶圖示和描述，並可自行決定是否顯示圖示和描述 |

## 應用程式連結

透過 OAuth 連結社交帳號，即可在個人頁面上展示它們。已連結的帳號會以圖示形式顯示在頭像下方。

| 平台 | 最新內容（僅限網格版面） |
|----------|-----------------------------------|
| X | 顯示您的最新貼文 |
| YouTube | 顯示您的最新影片 |
| GitHub | 顯示您指定的儲存庫 |

> **注意：** 已連結帳號的最新內容僅在 **網格** 版面中顯示。在 **列表** 版面中，僅顯示個人檔案圖示。

## 自訂網域

您可以透過以下兩種方式，在自己的[自訂網域](/docs/zh-TW/custom-domains)上託管個人頁面：

- **根網域** - 啟用 **設為根網域的個人頁面**，直接在網域根路徑（例如 `example.com`）提供個人頁面
- **路徑形式** - 在網域的某個路徑下（例如 `example.com/you`）提供個人頁面

## 統計分析

個人頁面擁有與[短連結](/docs/zh-TW/links)相同的統計分析功能。您可以在控制台檢視訪問量和流量詳情。

---

## 管理個人頁面

- **編輯** - 點擊 **... > 編輯**，可修改除網域和別名以外的任何設定
- **封存** - 暫時對訪客隱藏您的個人頁面，直到您重新啟用
- **刪除** - 永久移除個人頁面，並釋放其別名供新頁面使用
