## Überblick

Eine Bio-Seite ist eine persönliche Landingpage, ähnlich wie Linktree, die alle Ihre Links und sozialen Profile hinter einer kurzen URL bündelt. Perfekt für Social-Media-Bios und überall dort, wo Sie nur einen Link angeben können.

Ein Live-Beispiel finden Sie auf unserer offiziellen Bio-Seite unter [s.ee/see](https://s.ee/see).

---

## Eine Bio-Seite erstellen

1. Melden Sie sich bei [https://s.ee/user/dashboard](https://s.ee/user/dashboard) an
2. Klicken Sie in der linken Seitenleiste auf **Link-Verwaltung > Bio** oder gehen Sie direkt zu [https://s.ee/user/bio/](https://s.ee/user/bio/)
3. Klicken Sie auf **Bio-Seite erstellen**
4. Füllen Sie die Details aus:
   - **Titel** - Der Seitentitel, der im Browser-Tab angezeigt wird
   - **Domain** - Wählen Sie die Domain für Ihre Bio-Seite
   - **Alias** - Ihr Handle, das Teil der URL wird (z. B. `s.ee/you`)
5. Klicken Sie auf **Erstellen**

> **Wichtig:** **Domain** und **Alias** können nach der Erstellung nicht mehr geändert werden. Um eine andere Domain oder einen anderen Alias zu verwenden, löschen Sie die Bio-Seite und erstellen Sie eine neue.

Klicken Sie nach der Erstellung bei Ihrer Bio-Seite auf **... > Bearbeiten**, um sie anzupassen.

## Seiteneinstellungen

### Grundlagen

| Option | Description |
|--------|-------------|
| Titel | Der Seitentitel, der im Browser-Tab angezeigt wird |
| Vollständiger Name | Der auf der Seite angezeigte Name. Das kann Ihr eigener Name oder der Name einer Organisation sein |
| Profilbild | Laden Sie ein eigenes Profilbild hoch. Wenn Sie keines festlegen, wird Ihr [Gravatar](https://gravatar.com) verwendet |
| Beschreibung | Eine kurze Vorstellung, die auf der Seite angezeigt wird |
| E-Mail | Zeigen Sie Ihre E-Mail-Adresse mit einem Symbol auf der Seite an |

### Darstellung

| Option | Description |
|--------|-------------|
| Layout-Stil | Wählen Sie zwischen den Layouts **Liste** und **Raster** |
| Seitenthema | Wählen Sie ein integriertes Theme. Die verfügbaren Themes hängen vom gewählten Layout ab |
| Farbmodus | Wählen Sie **Hell** oder **Dunkel**. Einige dunkle Themes haben nur ein Farbschema und sehen in beiden Modi gleich aus |
| Hintergrundbild | Laden Sie ein eigenes Hintergrundbild hoch. Bei einigen Themes ist der Hintergrund fest vorgegeben und kann nicht geändert werden |
| Hintergrundfarbe | Legen Sie eine eigene Hintergrundfarbe fest. Diese steht im Konflikt mit einem eigenen Hintergrundbild, und bei einigen Themes ist die Hintergrundfarbe fest vorgegeben |

### Inhalt

| Option | Description |
|--------|-------------|
| RSS-Feed | Zeigen Sie einen Link zu Ihrem RSS/Atom-Feed an, optional mit dessen neuesten Einträgen (bis zu 5) |
| Mastodon-Profil | Zeigen Sie einen Link zu Ihrem Mastodon-Profil an, optional mit Ihren neuesten Beiträgen (bis zu 5) |
| Eigene Links | Fügen Sie bis zu 10 Links hinzu, jeweils mit optionalem Symbol und optionaler Beschreibung. Sie können wählen, ob Symbole und Beschreibungen angezeigt werden |

## Social Media

Verbinden Sie soziale Konten per OAuth, um sie auf Ihrer Bio-Seite anzuzeigen. Verbundene Konten erscheinen als Symbole unter Ihrem Profilbild.

| Platform | Latest Content (Grid layout only) |
|----------|-----------------------------------|
| X | Zeigt Ihre neuesten Beiträge |
| YouTube | Zeigt Ihre neuesten Videos |
| GitHub | Zeigt Repositories Ihrer Wahl |

> **Hinweis:** Die neuesten Inhalte verbundener Konten werden nur im Layout **Raster** angezeigt. Im Layout **Liste** werden nur die Profilsymbole angezeigt.

## Verifizierung

Sie können für Ihre Bio-Seite ein Verifizierungsabzeichen beantragen – einen blauen Haken für Einzelpersonen oder einen goldenen Haken für Organisationen. Details und die Vorgehensweise zur Beantragung finden Sie unter [Verifizierung von Bio-Seiten](/docs/de/link-in-bio-verification).

## Benutzerdefinierte Domains

Sie können Ihre Bio-Seite auf zwei Arten auf Ihrer eigenen [benutzerdefinierten Domain](/docs/de/custom-domains) hosten:

- **Root-Domain** - Liefern Sie die Bio-Seite direkt unter dem Root Ihrer Domain aus (z. B. `example.com`), indem Sie **Als Bio-Seite der Root-Domain festlegen** aktivieren
- **Pfadbasiert** - Liefern Sie die Bio-Seite unter einem Pfad Ihrer Domain aus (z. B. `example.com/you`)

## Bio-Seiten verwalten

- **Bearbeiten** - Klicken Sie auf **... > Bearbeiten**, um jede Einstellung außer Domain und Alias zu ändern
- **Archivieren** - Blenden Sie Ihre Bio-Seite vorübergehend für Besucher aus, bis Sie sie wieder aktivieren
- **Löschen** - Entfernen Sie die Bio-Seite dauerhaft und geben Sie ihren Alias für eine neue Seite frei
